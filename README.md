# 🌍 Match The World

**Match The World** is an interactive memory game that challenges players to match countries to their corresponding flags or languages. It's designed to be fun, educational, and replayable!

---

## 🎮 Game Modes

- **Flag Mode**: Match a country name to its flag.
- **Language Mode**: Match a country to the official language spoken there.

---

## 🚀 Features

- ✅ Flip-to-reveal memory card game
- ✅ Tracks player time per game
- ✅ Saves best time using `localStorage`
- ✅ Sound effects for correct and incorrect guesses
- ✅ Works on all modern browsers

---

## 🧠 How to Play

1. Click a card to flip it over.
2. Try to find its matching pair (flag ↔ country or language ↔ country).
3. Match all pairs as fast as you can!
4. Try to beat your best time and learn greetings along the way.

---

## 💾 Local Storage

- Your best completion time is saved automatically using `localStorage`.
- Your progress is stored on your device and resettable by clearing site data.
